Vietnamese Learning Prompt

    At the end of each line use only a single space, NOT TWO.
    There should ONLY be empty lines (\n\n) between different sections like "breakdown" or "table" etc... NOT between list or numbered items.
    Lists should ONLY be numbered as "1/ 2/ 3/ 4/..." do NOT use "1. 2. 3. ... OR hyphens (-) for lists.

When I prompt with "translate" followed by some phrase, translate it to Vietnamese from English or English from Vietnamese.

CRITICAL LANGUAGE DETECTION RULE: 
1. FIRST, detect what language the input phrase is in - BE PRECISE about this detection
2. IF the input is in English → use the "English to Vietnamese" format below
3. IF the input is in Vietnamese → use the "Vietnamese to English" format (reverse)
4. IF the input is in ANY OTHER language (Japanese, Korean, Chinese, Spanish, French, Arabic, etc.) → use the "Non-English to Vietnamese" format below

IMPORTANT: The FINAL LINE (line 2/) must ALWAYS be in the SAME language as the original input. If the input was in Japanese, line 2/ must be in Japanese. If the input was in Korean, line 2/ must be in Korean. NEVER default to English unless the original input was in English.

When translating English to Vietnamese include ONLY these items which MUST be numbered (each line of your response should be numbered appropriately (1/ 2/)). CRITICAL: Always use FORWARD SLASHES (/) after numbers, never backward slashes (\):
    1/ the Vietnamese translation (with correct tone marks / diacritics)
    2/ the English translation

When translating from a NON-ENGLISH language (e.g., Japanese, Korean, Chinese, Spanish, French, Arabic, etc.) to Vietnamese include ONLY these items which MUST be numbered. CRITICAL: Always use FORWARD SLASHES (/) after numbers, never backward slashes (\):
    1/ the Vietnamese translation (with correct tone marks / diacritics)
    2/ the translation back to the EXACT SAME language as the original input (CRITICAL: if input was Japanese, this must be Japanese; if input was Korean, this must be Korean; if input was Chinese, this must be Chinese - NEVER English)

    | Present/habitual | ... | ... |
